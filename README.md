# Static Site Generator

A simple static site generator built with Python as part of the [Boot.dev](https://www.boot.dev/) course.

It converts Markdown files into HTML pages using an HTML template.

## Features

- Converts Markdown to HTML
- Supports headings, lists, links, images, bold, italic, and code
- Generates pages from the `content` folder
- Copies CSS and images
- Deploys using GitHub Pages
